# 測試資料：來一碗大腸麵線（台中 5 家分店）

> 資料版本：schema 1.1.0｜整理日期：2026-10-23｜幣別：TWD（新台幣元）｜時區：Asia/Taipei
> 用途：多店家、菜單、套餐、外送平台、平台價差等情境的測試資料。真實品牌的公開資訊，**僅供測試，價格為外送平台標價，不是門市現場價格**。
> 機器可讀的完整原始資料在本檔最後的〈原始 JSON〉，可直接複製給其他程式使用。本檔的表格由該 JSON 以程式產生。

## 1. 資料規則（使用前必讀）

- 價格為各來源公開的外送平台標價，並非保證的門市現場價格。
- 只有來源頁面能確認的價格才填入 price；未查到價格的品項不硬猜。
- 平台折扣價與原價分開記錄；同一品項出現不同版本時保留來源觀察值。
- 官方菜單列出的品項不代表每家分店都有供應。
- 官方網站列出的冷泡茶僅健行店、軍福店供應；肉圓精誠店不供應；臭豆腐與泡菜部分店家不供應。
- 請勿將平台價格直接視為門市現場價格；營業時間與供應狀態可能變更。
- `price: null` 代表**尚未取得可核實的價格**，不是 0 元；各品項的未取得原因記在 `price_status`。

官方網站：<https://www.eateasy.com.tw/>｜官方菜單：<https://www.eateasy.com.tw/菜單介紹>

## 2. 與上一版（1.0.0，2026-10-20）的差異

- **價格大幅補齊**：健行店、大墩店、北屯軍福店的單點價格幾乎全部取得（來源 Uber Eats）；上一版這三店大多是 null。
- **套餐改放在各店菜單的「套餐」類別**，並新增 `includes` 列出內容（健行、軍福有；太平沒有）。健行店新增 5 種、北屯軍福店由 1 種增為 8 種、太平中山店由 5 種增為 8 種套餐。
- **門市資訊更新**：健行、大墩、太平補上電話與付款方式；北屯軍福店電話改為 04-3607-5272、地址寫法改為「356之5號」、營業時間由「週一至週六 11:00–22:00、週日 11:00–19:00」改為「每日 11:00–20:00，不定時公休」。
- **太平中山店有兩個價格變回未取得**：大腸麵線（大）、肉羹麵線（大）上一版為 80 元，這一版來源頁未讀到而改為 null（依「未查到不硬猜」原則）。
- **大墩店平台價改為對照表**：上一版的 Uber Eats 多版本觀測價（70／75 等）改為菜單直接填 Uber Eats 標價（大腸麵線小／大為 75／90，與上一版其中一個觀測版本相同），foodpanda 原價與折扣價另存 `platform_price_comparison`，由 3 項增為 12 項。
- **品項名稱改用平台上的寫法**：「冷泡茶」→「高山冷泡茶」、部分店「古早味紅茶」→「紅茶」；新增「小包裝辣椒」；移除茉莉綠茶、健行店的手作辣椒，以及健行、軍福的蘿蔔魚丸湯（改列綜合湯、蘿蔔湯）。北屯軍福店只保留 1 個 Uber Eats 頁面。
- **欄位改名**：`business_hours` → `hours`（`verified` → `source`）、`availability_notes` → `unavailable_items`、`menu_catalog` → `brand.official_menu_catalog`（只列官方菜單品項，另有 `official_supply_notes`）、`price_conflicts`／`coverage` → `quality_control`。舊版資料需要時可從 git 歷史取回。

## 8. 匯入本系統的對應建議

| 原始資料 | 本系統 | 建議 |
|---|---|---|
| `branches[]` | `stores` | 一家分店一筆；`branch_id` 作為店家代碼或外部識別碼保存 |
| 分店 | `warehouses` | 每店至少一個倉庫（建立店家時會自動建立預設倉） |
| `menu[].category` | 菜單分類 | 每店一份菜單，類別照原始資料（含「套餐」） |
| `size: 小／大` | 菜單品項 | 建議拆成兩個品項（例「大腸麵線（小）」「大腸麵線（大）」），小大份價格各自獨立，不用推算加價；精誠店的不分大小麵線就建一個品項 |
| `price: null` | 品項價格 | 不要匯成 0 元。測試時給明顯的佔位價，並在品項備註寫「價格未核實」 |
| 平台標價 | POS 售價 | 這份價格都是外送平台標價，做 POS 門市測試時要清楚標示「以平台價代用」 |
| 套餐 `includes` | 套餐品項＋連結商品 | 套餐建為一般品項，連結商品設定組成內容以便扣庫；「紅茶；飲料可更換」可建成單選選項組（預設紅茶，其他飲料依店家規則加價，資料沒有加價金額） |
| `unavailable_items` | 不建立該品項 | 精誠店不建立肉圓 |
| 外送平台 `sources` | 外送平台設定 | URL 末段是平台頁面識別碼，**不保證等於 API 用的 Store ID／Vendor Code**，正式串接須以平台後台提供的值為準 |
| 品項名稱 | 外送品項對應 | 平台名稱與官方名稱不同時（紅茶／古早味紅茶、高山冷泡茶／冷泡茶），用外送品項對應表或對應模板處理，不要改菜單名稱去配合平台 |
| `platform_price_comparison` | 不匯入菜單 | 只作為「同一品項兩個平台價格不同」的測試對照 |
